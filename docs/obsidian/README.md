# Obsidian ile proje notları

Obsidian kasasının tamamı kişisel olduğu için public GitHub reposuna gönderilmez.

Bu klasörde yalnızca Indirimci projesiyle ilgili, paylaşılabilir teknik notlar tutulur. Kişisel günlükler, özel düşünceler, parolalar ve API anahtarları Obsidian kasasında kalır.

Ana proje kaydı Obsidian içinde `01-Projeler/Indirimci.md` dosyasındadır. GitHub’daki teknik kaynaklar ise `KNOWN_ISSUES.md`, `PROJE_NOTLARI.md` ve bu klasördedir.
